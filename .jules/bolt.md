## 2023-10-21 - [Fast Read via Unaligned Pointers for `std::io::BufReader<R>` in `bincode-next`]
**Learning:** In `bincode-next`, `std::io::BufReader<R>` implements a custom `read_u*` override using `peek_read`. The default implementation constructed integers from an array of individual bytes accessed by index (e.g. `[buf[0], buf[1]]`). Replacing this with a direct unaligned memory read (`core::ptr::read_unaligned(buf.as_ptr().cast::<T>())`) matches the behavior in `SliceReader`, producing a measurable speedup for integer decoding off a buffer, especially for varint decodes, which frequently hit this code path.
**Action:** When optimizing byte parsing from memory slices in Rust (where the length is statically guaranteed to be long enough), consider reading memory directly via `core::ptr::read_unaligned` instead of array index construction, which allows the compiler to generate more optimal loads.
